# 万界武库自用版（1.0.0-ziyong.1）

本扩展改自 feiluoze/wanjie-wuku 1.0.0（MIT，版权归“万界武库项目贡献者”）。原 LICENSE 和 NOTICE.md 原样保留；自用版只供个人使用。
原版内置的万界武库 V4.1 规则文本属于原作者，不在 MIT 许可范围内，本版已经删除，不再随包分发。

## 和原版的区别
- 扩展名改为“万界武库自用版”，设置命名空间改为 wanjie_wuku_ziyong，可以和原版分开保存设置（界面 CSS 前缀没改，见下面的注意事项）。
- 删除了内置的 119 条规则。规则来源只用你自己选的世界书；读取世界书时，名字含“万界武库”的会被默认选中（优先 v6/V6，其次最高 vN，再次 _fixed）；15 条常用词条按名字自动预选。
- 插件里所有 AI 任务（整理、拟定、纠错等）都会附带一段自用版规则说明，内容包括：双面玫瑰的各项字段、气味三档、不凋和“借春”、四栏结算加进度行，以及匿名的“有人在想着你”。
- 对角色卡的 MVU 变量只读：删掉了变量写回（replaceMvuData）、往楼层追加回执、改写正文这几个功能。点到这些功能时会提示“自用版只读”。这样不会和未定性青春卡的校验器打架。
- 不要求也不注入 <WJWK-think> 和 <WJWK-option>。
- 默认设置：连接方式“跟随酒馆”，正文后自动整理关闭，详细日志关闭，主题“魅魔纹”。

## 安装
方式一（推荐）：把 wk_fork.zip 解压，得到 wanjie-wuku-ziyong 文件夹，放进
  SillyTavern/public/scripts/extensions/third-party/
然后刷新网页。
方式二：酒馆的“安装扩展”只认 Git 地址。要用这种方式，得先把这个文件夹推到你自己的私有仓库，再填那个地址。

注意：不要和原版“万界武库通用插件”同时启用，两者的界面样式类名相同，会互相干扰。

## 推荐设置
1. 先在酒馆里导入并绑定你的万界武库世界书（如 万界武库v6）。
2. 在插件的“金手指与角色接入”里选择这个世界书读取，只接入你实际在用的词条。
3. 连接方式保持“跟随酒馆”；正文后自动整理保持关闭，需要时手动点“AI 整理当前情况”。
4. “发送档案给正文 AI”可以开，它会在每次请求里附带你的档案。
5. 预设用 preset_fixed.json，里面已经有结算美化正则（魅魔纹）。

## 限制
- 原版里依赖内置规则的功能（例如“漫漫长路”“太始天”自带的统计规则）可能显示为空，或者需要你在世界书里自己提供对应条目。
- 所有模块都通过了语法检查，也能在 Node 里正常加载。原版自带的测试很多依赖内置规则和浏览器环境，在这里没有跑完，所以还没有在真实的酒馆里验证过。
